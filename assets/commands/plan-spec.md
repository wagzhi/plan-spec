---
description: 使用 plan-spec 技能规划、完善或执行任务计划
---

请加载并使用 plan-spec 技能，根据当前会话上下文和当前 agent/Mode 处理以下请求，遵守技能的阶段判断与安全边界。

命令参数：$ARGUMENTS

Plan agent 中，有需求或完善意图则按技能规划或迭代；没有需求则询问需求，不执行。Build agent 中，优先遵循明确的新需求、计划完善请求或指定计划；若无新需求且当前会话有本技能形成、可唯一识别的未完成计划，则继续执行。"执行"、"开始"等明确的执行意图按技能规范处理；计划目标不明时由技能决定如何提问，不猜测旧计划。
